ASTRA¶

Agentic Schema for Transparent Research Analysis. The analysis document, astra.yaml: the files an analysis reads, the artefacts it makes, and the decisions it makes along the way.

URI: https://w3id.org/astra/analysis

Name: analysis

provenance¶

The provenance record: what a runner writes for each result it makes, saying what the result is and the run of the recipe that made it. Through this schema a record maps onto W3C PROV-O.

URI: https://w3id.org/astra/provenance

Name: provenance

Runner The software that ran the recipe and wrote the record.
