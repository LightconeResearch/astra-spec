# v0.1 schema: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace astra-spec's schema, build and specification with the v0.1
design. The result is a LinkML source whose generated JSON Schema is the
contract, fixtures that test that contract exactly as a consumer would, and a
normative specification.

**Architecture:** Hand-written LinkML modules (`types`, `analysis`, `insight`,
`provenance`) in `src/astra/schema/`. A small subclass of LinkML's JSON Schema
generator (`tools/jsonschema_generator.py`) produces the committed contract
in `src/astra/schema/generated/`. Every fixture is validated by plain
`jsonschema` against those committed files. The package ships no Python.

**Tech Stack:** LinkML 1.12.1 (dev only), JSON Schema 2019-09, `jsonschema`,
`ruamel.yaml` (YAML 1.2 loading in tests), pytest, just, uv, hatchling.

**Spec:** `design/2026-11-03-v0.1-schema-design.md`, called "the design"
below, with sections written §n. Read it before any task: it holds every
decision (D1–D12), and this plan only says how and in what order.

## Global Constraints

- **Commands:** this machine is NixOS without `uv` or `just` on `PATH`. Run
  every command in this plan as
  `nix shell nixpkgs#uv nixpkgs#just --command <command>`. The plan writes
  them bare.
- **`pyproject.toml`:**
  - `requires-python = ">=3.10"`
  - `dependencies = []`
  - dev group exactly: `linkml==1.12.1`, `jsonschema>=4.23`,
    `ruamel.yaml>=0.18`, `pytest>=8`
- **Python:** no Python files under `src/astra/` (D7). Build-time Python lives
  in `tools/`.
- **Validation:** with `jsonschema.Draft201909Validator(schema)` and no format
  checker. Never with LinkML, pydantic or dataclasses (D1).
- **Loading YAML** in tests: `ruamel.yaml.YAML(typ="safe", pure=True)`, which
  is YAML 1.2 and raises on duplicate keys. Never PyYAML.
- **Generated artefacts:** live in `src/astra/schema/generated/` and are
  committed. Every task that changes a schema module runs `just gen-schema`
  and commits the regenerated files with the change.
- **Element ids:** a slot named `id` with `key: true` and `range: id`. Never
  `identifier: true`, except `Environment.iri` (D4).
- **Maps and lists:** a map is `multivalued: true` plus `inlined_as_dict:
  true`. A list of objects is `multivalued: true` plus `inlined_as_list:
  true` (D2).
- **Regex:** patterns stay in the subset ECMA-262 and Python `re` share.
  - anchored `^…$`; lookahead allowed
  - no lookbehind, no named groups, no `\A`/`\Z`
  - write `[0-9]`, never `\d` (Python's `\d` matches non-ASCII digits)
- **Descriptions:** LinkML descriptions are the normative definition of each
  field (D8). One or two sentences, present tense, saying what the field is and
  what it takes. No history ("no longer", "was", "replaces").
- **Schema module headers:** `version: 0.0.0` (the placeholder; `just` stamps
  it), `license: https://creativecommons.org/licenses/by/4.0/`, prefix
  `astra: https://w3id.org/astra/`, `default_prefix: astra`,
  `default_range: string`, as on `main`.
- **Invalid fixtures** start with exactly two comment lines:
  - `# rule: <CODE>`, a code from the design §7
  - `# fails at: <JSON Pointer>`, or `(root)` for the document, or `parse`
- **Error locations,** as `jsonschema` reports them (the pointer a fixture
  names):

  | What fails | Location |
  |---|---|
  | missing field, unknown field, `exactly_one_of`, rules | the object |
  | bad map key, empty map | the map |
  | wrong value or wrong type | the value |
- **Out of scope:** `Recipe`, `Resources` and both `container`s (fields
  unchanged), `when`'s semantics, every docs page except
  `docs/specification.md`, astra-tools.
- **Commits:** one at the end of each task. Every commit message ends with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

Inputs the design implies but no task's main tests exercise, most likely to
bite first. Each has its test in the task named.

1. **Words YAML 1.1 treats as booleans** (`yes`, `no`, `on`, `off`) used as
   option or decision ids. Under YAML 1.2 they are strings, so they are valid
   ids: `Analysis-003-yaml-1-2-keys.yaml` (Task 4).
2. **An unquoted all-digit commit id** (40 digits). YAML reads it as an
   integer. It fails as `WRONG_TYPE` at the commit, not silently:
   `Analysis-153` (Task 5). The spec tells authors to quote commit ids
   (Task 10).
3. **Windows paths** (`data\x.csv`, `..\stage`). Paths are `/`-separated, so
   these fail as `INVALID_PATH`: `Analysis-128` (Task 4), `Analysis-156`
   (Task 5).
4. **A `url` that can't be a remote** (`url: " "`, `url: a`, `url: ../repo`).
   It fails at the schema (`INVALID_VALUE`), not later at fetch time:
   `Analysis-157`, `-178`, `-179` (Task 5).
5. **Keys with stray whitespace or non-ASCII letters** (`"two "`, `séed`).
   These fail as `INVALID_ID`: `Analysis-103` (Task 4), `Analysis-177`
   (Task 6).

### Task 2: The JSON Schema generator extension

**Files:**

- Create:
  - `tools/jsonschema_generator.py`
  - `tests/generator/maps.yaml`
  - `tests/test_generator.py`

**Interfaces:**

- Produces:
  - `class AstraJsonSchemaGenerator(linkml.generators.jsonschemagen.JsonSchemaGenerator)`
  - `generate(schema: str | Path, *, closed: bool = True) -> dict`: the JSON
    Schema as a dict, always with `include_null=False`, with
    `not_closed = not closed`
  - CLI: `python tools/jsonschema_generator.py SCHEMA [--not-closed]` writes
    `json.dumps(generate(...), indent=2)` and a newline to stdout

**`tests/generator/maps.yaml`** is a scratch schema, not ASTRA:

- a type `local_id`, pattern `^[a-z][a-z0-9_]*$`
- `Root` (`tree_root`):
  - `things`: map of `Thing`
  - `picks`: map of `Pick`
  - `required_things`: map of `Thing`, `required: true`,
    `minimum_cardinality: 1`
  - `note`: an optional string
- `Thing`: `id` (key, `local_id`), `label`, `size` (integer)
- `Pick`: `name` (key, pattern `^[a-z]+(\.[a-z]+)*$`), `choice` (required,
  `local_id`)

Every test document carries `required_things: {r: {}}` unless the test is
about it.

- [ ] **Step 1: Write the failing tests** in `tests/test_generator.py`. Each
  builds a validator from `generate("tests/generator/maps.yaml")`.

  ```python

  def test_the_key_is_not_repeated_in_the_entry(): # things {"a": {"id": "a"}} ✗
  def test_key_plus_one_slot_is_compact_only():    # picks {"x.y": "foo"} ✓, {"x.y": {"choice": "foo"}} ✗, {"x.y": "Foo"} ✗
  def test_optional_fields_reject_null():          # {"note": None} ✗
  def test_required_maps_keep_one_entry():         # required_things {} ✗
  def test_open_variant_allows_unknown_fields():   # {"extra": 1, ...} ✗ closed, ✓ generate(..., closed=False)
  def test_cli_writes_the_same_schema():           # subprocess CLI stdout parsed == generate(...)
  ```

- [ ] **Step 2: Run them and check they fail**

  Run: `uv run pytest tests/test_generator.py -v`

  Expected: FAIL (`ModuleNotFoundError: jsonschema_generator`).

- [ ] **Step 3: Implement `AstraJsonSchemaGenerator` and `generate`**

  Override `get_subschema_for_slot(self, slot, omit_type=False,
  include_null=True, cls=None)`. Call `super()`. Then, when the slot is
  multivalued, its range is a class, it isn't `inlined_as_list`, and the
  range has a key (`self.schemaview.get_identifier_slot(range,
  use_key=True)`), rebuild the map:

  - **`propertyNames`:** `{"type": "string", "pattern": <the key slot's
    pattern>}`, read from the key slot's subschema.
  - **`additionalProperties`:**
    - if the range class has exactly one slot besides its key: that slot's
      subschema, with `include_null=False`
    - otherwise: `{"$ref": "#/$defs/<Range>__identifier_optional"}`
  - **The key itself:** after generation (override `serialize`, or
    post-process in `generate()`), delete the key property from every
    `<Range>__identifier_optional` definition the maps reference, and from
    its `required`.
  - **Leave the rest as LinkML made it:** `type`, `minProperties`.

  Run: `uv run pytest tests/test_generator.py -v`

  Expected: 8 passed.
